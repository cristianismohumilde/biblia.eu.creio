# SOURCES-LICENSES

Status de verificação de fontes e licenças de dados textuais do projeto.

Data desta revisão: 2026-04-17

## Situação atual (MVP)

- O repositório contém apenas um verso de demonstração em `data/verses/gen.1.1.json` para validar interface e estrutura.
- Nesta fase, os dados servem como conteúdo de protótipo e não como edição crítica oficial completa.

## Verificação realizada

- Código: licença MIT em `LICENSE`.
- Política de dados: regras de uso em `LICENSE-DATA`.
- Fonte textual oficial para produção: ainda não cadastrada neste repositório.

## Antes de publicar base textual completa

- Registrar para cada dataset: origem oficial, URL, licença, data de coleta e transformações aplicadas.
- Adicionar arquivos de metadados por fonte em `data/sources/`.
- Publicar apenas datasets com licença compatível para redistribuição.

## Risco legal atual

- Baixo para o protótipo técnico atual.
- Moderado/alto se textos completos forem adicionados sem trilha de licença por fonte.

## Próxima ação recomendada

- Criar um manifesto de fontes por idioma (hebraico, grego, aramaico, latim e PT) antes de ampliar os dados.
